WhatsApp · Evolution API

Para a conexão real, configure um endpoint intermediário seguro (n8n/backend). O HTML não deve armazenar a chave da Evolution API. O backend deve consultar o QR Code, o estado da conexão, enviar mensagens e receber webhooks. Os formatos variam entre versões da Evolution API.

Mensagem padrão WhatsApp

Esta regra vale para o produto selecionado. Edite a mensagem e clique em Salvar configurações.

Use {nome} para personalizar com o primeiro nome do contato.

Rotas esperadas: GET /qr, GET /status, POST /send, GET /messages?contactId=... e POST /schedule. Essas rotas precisam ser implementadas no backend e podem exigir autenticação.

O Kanban, o histórico local e o agendamento demonstrativo funcionam sem API. Sincronização, QR Code real, mensagens e envios agendados exigem o backend conectado e os eventos da Evolution API.
